# AgentML

This is a small sketch of what my ideal language layering might look like.

The core is readable logic. Types, lifetimes, invariants, and performance are different views of the same program—things you can reveal when you need them, rather than details you have to hold in your head all at once. The Unified view brings those layers together; the Logic view lets you explore them inline.

This is an exploration, not a language specification or a compiler.

[Try the demo](https://agentml.leostera.dev).
